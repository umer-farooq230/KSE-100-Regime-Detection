# Data

This repo does not hold raw data. We are not allowed to share most of it.

| Data | Why it is not here |
|---|---|
| KSE-100 prices (PSXpert CSV) | Where it came from is not documented |
| KSE-100 prices (Karandaaz) | Personal, non-commercial use only |
| News text and headlines | Owned by the publishers |

## To run the code yourself

1. Get the price data from the sources listed in [docs/05-data.md](docs/05-data.md). Follow each source's own terms.
2. Put the files in `data/raw/`. This folder is ignored by git.
3. Scripts to clean and check the data will be added in `src/` at Milestone 3.

What we share instead: the checks we ran, the numbers they gave, and the code that makes them.
